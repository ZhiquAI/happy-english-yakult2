> 西安经开第一学校 一年级快乐英语点读闯关互动应用

在线体验地址：**[https://zhiquai.github.io/happy-english-yakult2/](https://zhiquai.github.io/happy-english-yakult2/)**

## 🌟 核心特色与功能

1. **原声伴读与逐词点读**
   - 提取自官方《养乐多2音频.m4a》原声录音，精准对齐毫秒级时间戳。
   - 点击任意自然拼读卡片、单词、口语对话、指令或儿歌，即刻原声发音！
   - 支持**点读模式**与**连续伴读模式**（自动由上至下连续播放并自动滚动高亮）。

2. **全卡片精美配图**
   - **自然拼读 (Magic Phonics)**：为 `apple` 🍎、`banana` 🍌、`cat` 🐱、`dog` 🐶、`egg` 🥚、`fan` 🪭 配齐可爱卡通贴纸配图。
   - **单词闯关 (I Can Read)**：提取教材原版高清水彩插图（铅笔、尺子、橡皮、书本、文具盒、书包、展示、开、关、数字 1-6）。
   - **趣味数字儿歌 (Number Rhymes)**：数字记忆口诀图文并茂（1 像铅笔细又长、2 像小鸭水上漂、3 像耳朵听声音、4 像小旗随风飘、5 像钥匙开大门、6 像哨子吹得响）。

3. **第二页：整理书包口语秀 (Pack My Schoolbag)**
   - 支持输入学生**英文名**与**班级**，自动将个人信息融入展示句型中。
   - 逐句示范朗读（标准清晰美音）。
   - **互动小游戏**：点击铅笔、尺子、橡皮、书本、文具盒，道具自动装入书包，并朗读口语句型，全部装好后获得表扬与音效。

4. **个性化辅助功能**
   - **语速调节**：支持 `0.8x 慢速`、`1.0x 正常`、`1.2x 挑战` 切换，适合初学者逐步跟读。
   - **中英切换**：一键切换“中英对照”与“纯英沉浸”模式，考查孩子自主认读能力。
   - **自我评价体系**：还原教材评价标准，可点亮 1-3 瓶“能量养乐多”自我评星。
   - **老师原声寄语**：包含课前指读坐姿提醒与关卡结语原声鼓励。
